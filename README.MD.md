# 📚 Library Management System (Python)

A simple and beginner-friendly **Library Management System** built using Python.  
This project allows users to add books, view available books, borrow books, return books, and search for books.

Perfect for learning:
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements

---

## 🚀 Features

- ➕ Add new books  
- 📖 View all books  
- 📕 Borrow a book  
- 📗 Return a book  
- 🔍 Search books by title or author  
- 🟢 Check availability status  
- Simple and clean menu-driven interface

## 🧠 How It Works

### 1. **Adding a Book**
You enter the book title and author.  
The system stores it with an "Available" status.

### 2. **Borrowing a Book**
- Shows list of books  
- You choose a book number  
- If available → it becomes "Not Available"

### 3. **Returning a Book**
- Shows list again  
- Choose book number  
- Status becomes "Available"

### 4. **Searching for Books**
Search any keyword in:
- Title  
- Author  

Example:

Search: potter

Results:

Harry Potter by J.K. Rowling – Available
